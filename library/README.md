# Demo library (Phase 2)

Reusable Creatio demo modules harvested from real deals, generalised (no customer names, `lab` prefix), each with a
manifest, builder scripts, seed data, screenshots and the pains it solves. `catalogue.json` lists them;
`sc-first-meeting` and `sc-demo-plan` check it before planning a new build.

First candidates: H&G build board, template builder and sales overview; Suntory outlet 360 and visit briefing agent;
SAHE student recruitment.
