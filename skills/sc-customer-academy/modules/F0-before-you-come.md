# Before you come (about 30 minutes, with your IT team if you need them)

**Do this before the session.** Without it, the session turns into installing software.

## You need

- [ ] **A laptop** where you can install software (or IT does it with you).
- [ ] **A Claude plan that includes Claude Code** (Pro, Max, Team or Enterprise) and the Claude desktop app.
- [ ] **A test copy of Creatio** (a development or sandbox site), **not** the one your business runs on, and your own
      login for it.

## Set it up (about 20 minutes)

Follow the guide for your computer. Each one has a prompt you paste into Claude Code: Claude installs **clio** (the
tool Claude uses to talk to Creatio) and **Creatio's AI App Development Toolkit**, then gives you one command to
connect your test site yourself.

- **Windows:** [Set up Claude to build in Creatio (Windows)](F0-install-windows.md)
- **Mac:** [Set up Claude to build in Creatio (Mac)](F0-install-mac.md)

You type your Creatio password only in your own terminal window. Never paste a password into Claude.

## Check it works (2 minutes)

The guide ends with a check prompt. You should see your **sandbox** site and a list of apps. If you see your live
site, or an error, send a screenshot to your Creatio contact before the session.

## For the facilitator

- Send this and the two install guides a week before; check each participant's answer the day before (a screenshot
  of the check is enough).
- No working check = they pair with someone who has one. Don't install in the session.
- Creatio's own setup-wizard page on Academy returned 404 on 16 Nov 2026, so the guides install by prompt instead.
  Neither guide has been tested end to end on a clean machine yet: on the first run, be on a call.
