# Before you come (15 minutes, with your IT team)

**Do this before the session.** Without it, the session turns into installing software.

## You need

- [ ] **A laptop** where you can install software (or IT does it for you).
- [ ] **Claude Code** installed and signed in.
- [ ] **Creatio's AI toolkit** installed with Creatio's setup wizard (Creatio Academy: "Set up the Creatio AI app
      development toolkit"). It also installs **clio**, the tool Claude uses to talk to Creatio.
- [ ] **A test copy of Creatio** (a development or sandbox site), **not** the one your business runs on.
- [ ] **That test site connected:** your IT team or you register it in clio with your own login. Never paste a
      password into Claude.

## Check it works (2 minutes)

Open Claude Code and type:

> Which Creatio sites can you see? List the apps on the test one. Don't change anything.

You should see your **test** site and a list of apps. If you see your live site, or an error, tell your Creatio
contact before the session.

## For the facilitator

- Send this a week before; check each participant's answer the day before (a screenshot of the check is enough).
- No working check = they pair with someone who has one. Don't install in the session.
