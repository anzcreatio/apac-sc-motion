# Words you'll hear (one page)

| Plain words | Creatio word | What it means |
|---|---|---|
| Your test site | Development or sandbox environment | A copy of Creatio to build and try things in. Not the one your business runs on |
| Your live site | Production environment | The Creatio your business uses every day. Nothing is built here directly |
| Your folder of changes | Package | Everything you build is kept together in one package, so it can be reviewed, moved to live, or removed |
| A list of things you track | Object (or section) | Clients, sites, inspections: each is an object with its own list and pages |
| A field | Column | One piece of information on a record, like a date or a name |
| A dropdown | Lookup | A field where you pick from set values, like Pass / Fail |
| A page | Page (form page, list page) | The screen where you see and edit a record, or the list of records |
| A rule on a page | Business rule | "Show this field when…", "make this required when…" |
| The plan | Business Plan | What Claude will build, in business words, for you to approve first |
| Moving to live | Deployment | Your IT team's routine to get a change from test to live safely |
| The toolkit | Creatio AI App Development Toolkit | The add-on that lets Claude build in Creatio |
| clio | clio | The tool Claude uses to talk to your Creatio site |
